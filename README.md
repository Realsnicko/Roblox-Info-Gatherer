# Roblox-Info-Gatherer
small script that gathers info on a roblox account based off of an input keyword.
i used python v3.13.7, not sure how different each version of python3 is.
basically just takes an input keyword and gathers profile names, badges, friends, etc.
might be broken. this was one of my first ever programs, made it around the start of 2025. feel free to fork and patch it if you want.
